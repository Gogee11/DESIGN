## 0. 一句话总结

LLM-AGR 默认配置在 MIA 下**反而比 LightGCN 更不安全** (AUC +3.4 pp)。元凶是 `str_weight` (结构对比损失)。设为 0 即可获得 Pareto 改进;再加 M4 对抗训练 / M1 置信度正则 / M3 嵌入压缩 任一,在不损推荐前提下进一步降 AUC 1.5-9 pp。

## 3. 五大核心 finding (论文 5 个主章节)

### L1 反直觉发现:LLM-AGR 默认更不安全
- LightGCN baseline (3 seeds): R=0.238±0.002 / AUC=0.896±0.005
- AGR default (3 seeds): R=0.252±0.002 / AUC=0.934±0.003
- **AGR 推荐 +1.4%,但 MIA AUC +3.8 pp** — 引入 LLM 增强反而更易被攻击

### L2 机理识别:str_weight 是元凶
- (β, str_weight) 3×3 网格:str_weight 0→0.05→0.2 → AUC 0.886→0.93→0.95
- β 0→1→4 列内 ±0.02 (微弱影响)
- prf_weight 一直保持 0.002 (有益但弱)
- **aug_top_k ∈ {0, 3, 10, 20} 全部 IDENTICAL** → LLM kNN 增强图本身无关
- → LLM-AGR framework 真正起作用的部分仅 PRF 语义蒸馏

### L3 防御方法 (三类各代表论文)
- M1 (置信度正则): MemGuard 风格 (Pereyra'17, ICLR Workshop)
- M4 (对抗判别器): GRL minimax (Nasr-Shokri-Houmansadr CCS'18)
- M3 (嵌入压缩): 容量限制 (经典 ML 知识)
- **轻量 M1+M4 combo (s1_combo_c0.5_a0.1) 是论文最佳推荐**

### L4 鲁棒性
- 多种子 (seed 2025/2026/2027) variance 全部 <0.005
- 度数均衡 MIA 下相对排序保留
- LR vs MLP 攻击器排序一致 (MLP 略强 +1pp)

### L5 极端隐私
- emb=2 推到 AUC=0.714 (突破"度数下界"0.90)
- 完整 Pareto 曲线 emb={2,3,4,6,8,10,12,16,20,24,32}
